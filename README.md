# Parasuraman D. — Portfolio

A responsive, static portfolio website built from the details in Parasuraman's resume. It uses plain HTML and CSS, with no build step or external libraries.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a public GitHub repository named `Parasuraman8.github.io`.
2. Upload `index.html`, `styles.css`, and this README to the repository root.
3. In the repository, open **Settings → Pages** and select **Deploy from a branch**, using the `main` branch and `/ (root)` folder.
4. Save. GitHub Pages will publish the site at `https://parasuraman8.github.io/` after the first deployment finishes.

The GitHub and LinkedIn profile links, email, and phone number are included as provided in the resume. Review them before publishing if you want any details changed.
